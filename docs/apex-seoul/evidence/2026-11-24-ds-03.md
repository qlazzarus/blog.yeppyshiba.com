## 입력 계약

`TimeAttackScene.getDriveCommand()`는 매번 `arbitrateDriveCommand(mode, keyboard, virtual, motion)`을 호출한다. 키보드 좌우 입력의 차가 0이 아니면 해당 축을 사용한다. 양쪽을 모두 놓거나 동시에 눌러 차가 0이 되면 가상 버튼 표시와 같은 모드 정책을 적용한다.

| 모드 | 키보드 중립 시 조향 |
| --- | --- |
| full (4버튼) | 가상 버튼 축. 센서 대기·중단 시에도 적용 |
| pedals (센서 준비 완료) | 센서의 연속 축. 중립인 0도 그대로 사용 |
| hidden | 0 |
