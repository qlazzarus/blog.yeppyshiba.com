# DS-09 런타임 자산 고지 연결 계약 — 2026-11-25 KST

담당은 Codex이며 기준 commit은 `ce097ea39afd111435d0f2ba165170a715078cb5`다. DS-00 선행 근거와 기존 미커밋 변경을 확인하고 보존했다. 연결 계약과 관련 검사는 완료했다. 출처 및 라이선스 정보가 미확정인 자산이 있어 출처 검토 판정은 **REVIEW_REQUIRED**다.

## 연결 범위

- `startupAssets`의 32개 정의는 palette 확장 후 45개 로더 항목이며, 각 정의에 typed attribution ID를 연결했다. startup에서 실제 로드하는 구형 FT86과 G70 POC 및 차량 카탈로그의 G70 fallback도 포함했다.
- `RUNTIME_ASSET_PROVENANCE`에 고유 ID 17개를 기록하고 외부·프로젝트·미확정 출처와 게임·별도 vehicle-preview 사용 화면을 구분했다. 저자, 라이선스 URL, 원본 URL, 취득 시점, 수정 내용, metadata 참조 및 미확정 사항을 확인 가능한 범위에서 기록했다.
- Phaser 로더 밖의 PWA 아이콘과 라이브러리, vehicle-preview 모델과 라이브러리는 `ADDITIONAL_RUNTIME_PROVENANCE`의 12개 경로로 연결했다. preview 전용 출처는 게임 Credits에 표시하지 않는다.
- 실제 사용되는 배경, 연기, 차량 원본 및 Phaser를 게임 Credits에 연결했다. 사용되지 않는 원본은 제외했다. 달 텍스처의 CC0 1.0 버전은 [원본 페이지](https://opengameart.org/content/moon-overlay-texture)의 라이선스 링크에서 확인했다.
- 수동 정적 대조 결과 ID 17개가 모두 고유했고 startup 정의의 12개 연결 그룹에 알 수 없는 ID가 없었다. 기록된 metadata 경로는 모두 존재했다. 자동 coverage 검사는 DS-10 범위로 남긴다.

## 미확정 출처

`UNRESOLVED_RUNTIME_PROVENANCE`에는 다음 11개 기록이 남는다. 미확정 값은 추정하지 않았다.

- `oga-moon`, `kenney-smoke`의 취득일과 `oga-clouds`의 취득일 및 정확한 CC0 버전·라이선스 URL이 미확정이다.
- `menu-hero`, `pwa-icons`의 제작 또는 출처, 저자, 라이선스 및 시점을 확인해야 한다.
- `raven-ft86-source`, `seorin-stinger-source`, `legacy-g70-poc`의 원본 모델 metadata, 저자, 라이선스 및 취득일을 확인해야 한다. 구형 G70 POC와 Nieve G70은 별도 원본이다.
- `ft86-retro`의 입력 이미지와 실루엣의 원본 계보, 저자, 라이선스 및 취득일을 확인해야 한다.
- `mirae-g70-nieve`와 preview 전용 `genesis-coupe-preview`는 로컬 metadata에 CC Attribution으로 기록돼 있으나 정확한 버전과 URL이 없다. Nieve 원본 페이지 접근은 HTTP 403으로 차단됐다.
