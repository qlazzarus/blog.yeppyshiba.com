# DS-08 세 글자 이름 입력 UI

2026-11-26 KST, Codex 실행. DS-08 구현·자동 검증 완료.

## 기준과 선행

HEAD는 `b8f2d1b0a537b2b1d1ddc8a58288d334b7550643`이다. 시작 시 DS-07 저장 API, DS-11~13 오디오, DS-16과 실행 순서 문서 등의 작업 트리 변경이 있었다. 기존 변경 위에서 DS-08을 수행했다.

[DS-07](./2026-11-26-ds-07.md)의 runId 갱신·profile API와 [DS-04](./2026-11-24-ds-04.md)의 결과 화면을 확인했다. 이번 코드는 이 계약을 사용한다.

## 변경 내용

[결과 화면](../../../games/apex-seoul/src/game/resultScene.ts)에 native dialog와 세 개의 A–Z select, SAVE NAME, SKIP을 추가했다.

- 수락된 `recordRunId`가 있고 상태가 saved/memory-only인 결과에서 이름 입력을 연다. excluded 결과와 기존 ID 없는 payload는 기존 결과 화면을 표시한다.
- 마지막 확정 세 글자를 복원한다. 기존 기본 이름 `PLAYER` 또는 유효한 저장 이름이 없는 경우 초기 선택은 `AAA`다. 이 초기 선택은 사용자 지정이 없어 정한 UI 기본값이다.
- 글자별 native select를 touch로 선택하고 키보드 문자·위아래 선택 및 좌우 글자 이동을 지원한다. Enter는 저장, Escape와 SKIP은 이름 입력 닫기다. SKIP 버튼에 focus가 있으면 Enter도 닫기로 처리한다.
- dialog가 열린 동안 결과 화면 keyboard plugin을 비활성화하고 keydown 전파를 차단한다. repeat 입력을 무시해 저장 키가 Retry/Main으로 이어지지 않게 한다.
- 저장 API의 record/profile 결과를 모두 확인한다. 양쪽 성공 시 닫고, 기록 또는 마지막 이름 저장 실패 시 상태 문구와 재시도·CONTINUE를 제공한다. 기록 저장에 성공하면 기존 결과 화면의 저장 상태 표시도 갱신한다.
- 닫기·건너뛰기는 기존 완주 저장을 유지한다. shutdown 때 dialog, resize callback 및 결과 keyboard callback을 정리한다.
- native select와 action은 최소 48 CSS px 높이를 사용한다. 기존 Phaser 결과 화면의 Retry/Main과 레이아웃은 회귀 검사로 확인했다.

### 검증한 시나리오

- 844×390, 667×375, 640×360에서 세 글자 select와 저장/건너뛰기 버튼의 최소 44 CSS px 크기 확인
- native select 값 변경 후 실제 touch SAVE NAME, 해당 run의 이름·완주 count 확인
- 저장 Enter가 즉시 run을 재시작하지 않으며 이후 별도 Enter가 Retry를 한 번만 실행
- 마지막 ABC 복원, 키보드 Z/Y/X 입력과 좌우 이동·확정
- SKIP 시 PLAYER 보존, 실제 Main 버튼 tap, Escape 닫기 후 Result 유지
- excluded run에서 이름 입력 숨김
- storage setItem 실패 시 오류 안내, CONTINUE 후 Result 유지
- Scene 종료 시 dialog 제거, browser pageerror 0개
- 기존 desktop 기록 비교와 세 mobile viewport의 Retry/Main 각각 1회 전환 및 hit area 회귀

### 재실행 이력과 미검증

초기 브라우저 실행은 코드 수정 중 Vite reload와 route 종료가 겹쳐 실패했다. 이후 검사에서 SKIP 후 hover 상태를 고려하지 않고 ArrowDown으로 Main을 선택한다고 가정해 timeout이 발생했다. fixture를 실제 Main 버튼 tap으로 수정했다. 개발 서버 중단으로 한 차례 연결 거부도 발생해 서버를 재시작했다. 최종 고정 코드에서 두 browser suite와 빌드가 통과했다.

최종 검사 실패 0건, 실행 불가 0건이다. 빌드의 기존 500 kB 초과 chunk 경고가 남는다. Android/iOS 실제 native picker 동작은 미검증이며 Chromium에서는 selectOption으로 선택값을 변경하고 action은 touchscreen.tap으로 검증했다. 완주 전체 주행은 fixture 입력으로 대체했고 결과 화면 이후 경로를 검사했다. 실기기 통합 판정은 DS-17에서 추적한다.
