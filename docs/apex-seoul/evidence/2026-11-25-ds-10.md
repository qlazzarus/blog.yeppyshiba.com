### 연기 자산 사용 여부

`kenney-smoke`는 사용 중이다. 세 연기 PNG를 시작 로더에서 읽고 네 개의 연기 이미지 객체에 배정한다. 차량 렌더링에서 출발 번아웃 효과를 갱신하며, 출발 판정이 `hooked` 또는 `overrev`이고 번아웃 시간이 남아 있으면 이미지의 위치·크기·투명도를 설정하고 표시한다. 현재 일반 차량 중 Raven Coupe에 출발 제어가 활성화돼 있다. 내부 비교용 FT86에도 같은 경로가 연결돼 있다. 이 판정은 코드 추적으로 확인했다. ## 원본 페이지와 Git 이력 재확인

달 원본 페이지의 CC0 링크는 CC0 1.0으로 연결된다. 구름의 개별 Alpha05 페이지는 HTTP 403을 반환했으나, OpenGameArt 검색 색인의 원본 팩 설명에서 WickedInsignia의 CC0 배포 선언을 확인했다. 같은 팩의 Alpha03 페이지에서 CC0 링크가 CC0 1.0으로 연결되는 것도 확인했다. 로컬 README의 팩 이름·저자·파일명과 함께 대조해 구름을 CC0 1.0으로 정규화했다. 취득일은 두 자산 모두 기존 Git 대체일을 유지한다. ## FT86 레트로 제거 검증

일반 선택 차량은 Raven·Seorin·Mirae이며 레트로 FT86은 내부 비교 경로에만 연결돼 있었다. 사용자 승인에 따라 레트로 이미지 14개, 전용 atlas와 palette 검사 기록, 전용 후처리 스크립트까지 총 17개 파일을 삭제했다. 시작 로더의 색상 5개와 그림자 1개를 제거해 로더 항목은 45개에서 39개로 줄었다. 차량 카탈로그의 레트로 선택 경로, 전용 npm 명령, 고지 기록도 제거했다.

Raven 자산 생성 도구 세 곳이 사용하던 헤드라이트·그림자 수치는 별도 프로파일에 옮겼다. 두 데이터 구조가 삭제 전 HEAD의 값과 정확히 일치함을 검증했다. Raven의 3D 원본과 정상 렌더 자산은 계속 사용한다. [공용 렌더 프로파일](../../../games/apex-seoul/assets/vehicles/source/manifests/vehicle-render-profile-seed.json)

헤드라이트 검사의 입력을 현재 Raven atlas와 이미지로 바꾸고, 기존 중간·강한 조향 검증에 7방향의 slight 프레임 보간 검증을 추가했다. 카탈로그 검사는 삭제된 ID가 기존 unknown-vehicle fallback으로 처리되는지 확인한다. 브라우저 런타임 검사는 Raven으로 실행한다.

## 구현 및 최근 검증

게임 Credits와 동일한 출처 데이터에서 배포 고지를 생성한다. 빌드에서 생성 명령을 실행하고 Vite가 public 고지를 dist로 복사한다. 검사는 startup 39개와 추가 경로 12개, PWA 아이콘과 preview GLB 연결을 확인한다. npm은 샌드박스에서 실행할 수 없어 허용된 호스트 환경에서 검사했다. 빌드는 고지 검사와 별도로 실행된다. 현재 자산 출처 검사는 통과했다. 이번 삭제 검증에서 차량 카탈로그 10건, 헤드라이트 12개 방향 프로파일·19개 이미지 anchor, 브라우저 런타임 4건도 통과했다. 헤드라이트 검사는 초회에 7방향 slight 프레임을 기존 strong 프레임으로 분류해 실패했고 해당 프레임의 보간 계약을 추가한 뒤 통과했다. 브라우저 검사는 초회에 주행 진입 파라미터 누락으로 timeout됐고 진입 파라미터를 수정한 뒤 통과했다. 최종 실패와 실행 불가 검사는 없다.
