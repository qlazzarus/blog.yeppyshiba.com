# DS-05 메뉴 모바일 측정 — 2026-11-25 KST

담당은 Codex이며 기준 commit은 `ce097ea39afd111435d0f2ba165170a715078cb5`다. 시작 시 DS-03과 DS-04의 미커밋 변경이 있었다. [DS-04 증거](./2026-11-24-ds-04.md)에서 결과 버튼 완료 조건 통과와 별도 Records 회귀 실패를 확인했다. Node v24.12.0, npm 11.18.0, Playwright Chromium을 사용했다.

DS-05의 한 Scene 제한에 따라 `mainScene.ts`의 가로 모바일 버튼 높이를 조정했다. 버튼을 누른 동일 포인터가 10 CSS px 이내에서 놓을 때만 선택한다. 다른 화면에 대한 변경은 하지 않고 DS-05a~d에 분리했다. **DS-05 전체 자동 판정은 FAIL**이다. 여러 화면에 44 CSS px 미만의 action이 남아 있고 전체 완료 조건의 일부는 검증 대기다.

Garage는 현재 화면에 단계 이전으로 돌아가는 pointer action이 없고 메뉴로 바로 돌아가는 버튼이 있다. Records와 Credits에는 pointer 스크롤 구현이 있으나 실제 drag·shutdown 정리는 이번 회귀에서 확인하지 않았다. Options의 전체 설정을 포인터만으로 탐색하는 동작과 drag 오인, shutdown 정리도 미검증이다.
