## 설치 계약

- `getPwaInstallAction()`은 standalone 또는 `appinstalled` 뒤에 `null`, iframe에서 `open-game`, 사용 가능한 프롬프트가 있으면 `prompt`, 나머지 iOS 기기에서는 `ios-guide`를 반환한다. iframe action은 독립 게임 URL `/game-assets/apex-seoul/`을 새 탭으로 연다.
- `requestPwaInstall()`은 browser event를 첫 await 이전에 소비하므로 동시 요청이 같은 이벤트를 재사용하지 않는다. `prompt()` 또는 `userChoice`가 reject하면 `rejected`를 반환한다. 대기 중 새로 도착한 이벤트는 다음 요청에 사용할 수 있다.
- `subscribePwaInstall()`은 변경 알림과 구독 해제 함수를 제공한다. `destroyPwaInstall()`은 window 및 display-mode 리스너를 제거한다. Options는 이 API로 늦은 이벤트와 설치 상태를 반영하고 shutdown 시 구독을 해제한다.
- 기존 manifest의 게임 id·start URL·scope를 유지했다. 등록 함수의 worker URL과 scope는 각각 `/game-assets/apex-seoul/sw.js`, `/game-assets/apex-seoul/`으로 제한한다. worker의 기존 fetch 정책은 그대로다.
