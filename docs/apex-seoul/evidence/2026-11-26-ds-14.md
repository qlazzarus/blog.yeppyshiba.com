# DS-14 청음 후보 조사

2026-11-26 KST. 후보 비교 자료 준비, 사용자 선택 대기.

[청음 페이지](./2026-11-26-ds-14-listening.html)를 브라우저에서 열면 원본 5곡을 비교할 수 있다. 인터넷 연결이 필요하다. 작가 설명·태그를 바탕으로 비교 순서를 정했으며 사람의 청음 결과는 아직 없다.

Midnight Drive는 OGG와 MilkyTracker 소스 ZIP을 제공한다. Pure Raceway는 160 BPM 기본곡과 175 BPM climax를 제공하며 loopable로 명시돼 있다. 두 버전의 동시 stem 재생은 BPM 정합 검토가 필요하다. 나머지 곡의 BPM·key·정확한 loop 길이는 미확인이다.

Retroracing Nightlife는 CC BY 4.0 표기와 함께 작가 credit 및 Facebook 페이지 링크를 요청한다. 기존 계획의 CC0 우선 기준에 따라 runtime 채택에는 별도 선택·고지 확정이 필요하다. 라이선스 표기는 원본 게시 페이지에서 확인했다. [CC0 전문](https://creativecommons.org/publicdomain/zero/1.0/) · [CC BY 4.0 전문](https://creativecommons.org/licenses/by/4.0/)

## 청음 기록

각 곡의 첫 30–60초와 중간 부분을 비교한다. 선택 답변은 `레이스 / 메뉴 / 보류`와 곡 이름, 원하는 방향을 남기면 된다.

- 야간 서울의 화면과 어울리는가
- 코너를 반복해도 추진감이 유지되는가
- 선율과 고역이 엔진·변속음을 가리지 않는가
- 3분 이상 반복해 들을 수 있는가

## 검증과 남은 작업

원본 5개 게시 페이지의 작가·license·파일 링크를 확인했다. 기존 후보 Hot Roadway와 PYNCHON의 직접 페이지 요청은 403으로 응답해 이번 우선 청음 목록은 접근 가능한 후보로 구성했다. 브라우징 도구의 오디오 파일 열기는 지원하지 않는 content-type으로 종료됐다.

### 통과

- Playwright Chromium에서 청음 HTML을 열고 원격 오디오 5개 모두 `canplay` 도달을 확인했다. 기본 volume은 모두 0.35다.
- 브라우저가 보고한 길이는 Midnight Drive 203.57초, Pure Raceway 96초, StarShooter 85.33초, As fast as you can 90.67초, Retroracing Nightlife 162.29초다.
- `git diff --check` 통과.

### 실패·실행 불가

- 청음 페이지 자동 검사에서 실패한 곡은 없다.
- 브라우징 도구의 오디오 직접 열기는 content-type 지원 제한으로 실행 불가였다. Chromium의 실제 오디오 로드는 통과했다.

### 미검증

원본 파일 취득·가공, 전체 구간 decode·재생, loop 경계, BPM/key 정합, 실기기 청음, 사용자 채택은 미완료다. 현 단계는 DS-14의 후보 조사·청음 준비이며 최종 완료 판정은 대기한다.
