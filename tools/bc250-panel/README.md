# BC250 패널 확장 도구

저장소 루트에서 다음 명령을 실행합니다.

```sh
python3 tools/bc250-panel/extend.py
npx vite --host 127.0.0.1
```

브라우저에서 `http://127.0.0.1:5173/tools/bc250-panel/`을 엽니다. 생성된 `extended.stl`을 내려받거나 슬라이서에서 직접 엽니다. 기본 슬롯 사이 절단 위치는 원본 STL 좌표 Y=34mm이며 80mm 연장합니다. 원본 Y=1.05mm에서 BC250 바깥쪽으로 70mm를 추가하고 연장된 개구부를 채웁니다. 원본 최하단 0.05mm 구간은 그대로 남으므로 슬라이서에서 확인하세요. 필요하면 `python3 tools/bc250-panel/extend.py --length-cut 34`로 조정하고 브라우저를 새로고침합니다. 절단선이 구멍이나 장착 형상을 가로지르면 그 형상도 연장되므로 변경 후 반드시 확인하세요. 결과의 원래 좌표계는 유지됩니다.
