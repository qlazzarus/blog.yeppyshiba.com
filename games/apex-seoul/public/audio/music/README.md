# Apex Seoul runtime music

This directory intentionally contains no music files yet.

When an asset is approved, place the OGG file here using exactly one of the
filenames declared in `src/game/musicAssetManifest.ts`. The sound lab checks
these public URLs and will show `NOT PREPARED (404)` until a file exists.

Source originals and conversion candidates belong outside `public/`; only the
approved browser runtime OGG belongs in this directory.
