# Burnout smoke puff source

- Source: [Kenney — Smoke particle assets](https://opengameart.org/content/smoke-particle-assets)
- Author: Kenney (Kenney.nl)
- License: CC0 1.0 / public-domain dedication. Attribution is optional.
- Imported originals: `PNG/White puff/whitePuff00.png`, `whitePuff05.png`, and `whitePuff12.png`.

`burnout-puff-a.png`, `burnout-puff-b.png`, and `burnout-puff-c.png` are the original RGBA PNGs, renamed only. Runtime code downscales, tints, rotates, alpha-fades, and pools them for the short launch burnout burst; it does not alter their pixel data.
